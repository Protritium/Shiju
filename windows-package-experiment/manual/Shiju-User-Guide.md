# 拾句使用手册

版本：1.9.0  
适用系统：64 位 Windows 10/11

## 1. 启动与退出

安装完成后，从桌面或开始菜单打开“Shiju”。程序会显示一个本地服务控制窗口，并自动在默认浏览器中打开学习页面。

- 控制窗口中的“打开学习页面”可重新打开浏览器页面。
- 关闭浏览器不会删除进度，也不会立即停止程序。
- 关闭本地服务控制窗口才会停止拾句；下次可从快捷方式重新启动。
- 程序只监听本机 `127.0.0.1`，不会主动向局域网公开学习数据。默认使用端口 `8765`；如果 Windows 禁止或占用了该端口，程序会自动改用可用端口，控制窗口会显示实际地址。

## 2. 注册与登录

首次使用请选择“注册”，创建用户名和至少 6 位密码。登录成功后，应用会在这台电脑上默认恢复上次登录的账户，不必每次重新输入密码；主动点击“退出”才会清除持久会话。

- 不同用户的已学单词、错题本、每日目标和统计相互独立。
- 用户名、密码哈希及学习数据只保存在本机，不会上传到网络。
- 原始密码不会保存，但本地版本不提供密码找回，请妥善记录密码。
- 重启应用或服务后会自动恢复上次登录的账户，学习记录不会丢失。

## 3. 选择词书和学习形式

顶部“词书”可选择（新用户默认“高中 · 乱序”）：

- 六级 · 乱序
- 高中 · 乱序
- 考研 · 乱序
- 初中 · 乱序

四本词书的已学状态、错题本、历史错题、每日目标和统计分别保存。

内容形式可选择：

- 简单词组：更适合初学者快速识别搭配。
- 完整例句：在完整语境中学习，并在答案页查看整句中文翻译和例句来源；这是新用户默认模式。

## 4. 完成一道题

1. 根据高亮单词和语境，在输入框填写中文含义。
2. 按回车或点击“确认答案”。
3. 对照自己的答案、词书释义、整句翻译和内容来源。
4. 根据回忆情况选择“我记住了”或“加入错题本”。

答案展开后可使用键盘：

- `F2`：朗读当前词组或完整例句。空格完全保留给输入法选词和正常输入。
- `F3`：打开本地查词并自动聚焦搜索框；解析区也有“查词”按钮。
- `1`：执行左侧主按钮，通常表示记住并进入下一题。
- `2`：标记“回忆失败”，保留在错题本且不增加温习次数，再进入下一题。

## 5. 输入框快捷标记 `2`

如果不想填写释义，可在答案输入框中只输入 `2` 并提交：

1. 当前单词会先保存到错题本。
2. 页面仍会正常展开答案解析。
3. 此时按 `1` 只进入下一题，不会撤销刚刚保存的错词。
4. 该单词会被追加到本轮队尾，稍后再次出现。

这项锁定只针对本次通过输入框 `2` 产生的快捷标记。

## 6. 已学状态与错题循环

- 完成选择后，单词会标记为已学；已学且不在错题本中的单词不会自动重复出现。
- 同一拼写即使在原始词书中有多个词条，每轮也只出现一次。
- 错题会参与普通学习循环。
- 对错题按 `2` 或点击“回忆失败”会保留错题且不增加温习次数；当轮最多再出现一次。
- 对普通方式进入的错题按 `1` 会完成一次温习；累计完成第 3 次后才会将它移出错题本。
- 左侧“累计已学”按唯一单词统计。
- 普通学习时，左侧进度显示“累计已学唯一单词数 / 当前词书唯一单词总数”。进度来自账户数据，刷新页面或重新登录后不会重置为 `1 / 剩余队列数`。
- 错题列表和单个错题复习页面仍显示各自的错题数量与复习进度。
- 在“词书”下拉框选择“错题本 · 当前词书随机”，只安排今天尚未成功温习的错词。回忆成功每天最多累计一次；失败词当轮最多再出现一次。完成后可额外随机温习一轮，但不再累计次数。
- 每个曾进入错题本的单词都会永久写入该词书的历史错题。从“词书”选择“历史错题 · 第二轮随机”可以重新打乱全部历史错题；移除当前错题不会删除历史记录，在第二轮中再次标错会重新加入当前错题本。
- 程序会保存每个错词最近一次被标错时的输入。在错题列表单词复习、错题本随机和历史错题第二轮中，题目下方会展示这条记录；若当时输入的是 `2`，会注明当时表示不记得。

## 7. 回到上一题

选择后如果发现误点，可点击“上一题”查看答案并恢复该题作答前的状态；点击“回到背诵”可立即恢复原选择并回到当前进度。完成页和错题复习列表也提供回到上一题的入口。

回溯会同步撤销此前追加到队尾的重复项，避免产生额外循环。

## 8. 点击语境中的其他单词

答案揭晓后，语境中属于当前词书的其他单词会显示虚线标记。点击它会弹出小窗口，展示该词的：

- 词书释义
- ECDICT 音标、词性和补充释义
- 独立英文例句
- 例句中文翻译

当前目标词的答案区也会同时展示原词书释义与 ECDICT 补充释义。词书外单词保持普通文本外观，不显示虚线，但答案揭晓后仍可点击；确认查询后只展示内置词典释义，不提供例句，也不会加入已学或错题记录。点击关闭按钮、窗口外部或按 `Esc` 可关闭。

顶部“查词”支持直接输入英文或中文含义。输入“偷”可以找到动词 `steal`，输入“小偷”可以找到名词 `thief`；搜索 `steel` 或 `steal` 时还会显示同音易混提示。主动查询不会改变已学或错题记录。

## 9. 错题本

顶部点击“错题本”可查看当前词书的全部错词。

- 点击单词进入复习页面。
- 每个错词都会显示已温习次数；完成第 3 次温习前，“移除”按钮保持禁用。
- 第 3 次温习选择记住后，或温习次数超过 2 时点击“移除”，可移出当前错题本。
- 选择“回忆失败”会保留错题，但不会增加温习次数。

## 10. 每日目标与统计

左侧可设置当前词书的每日学习目标，并查看：

- 今日学习单词数
- 今日错题数
- 累计已学单词数
- 最近 30 个有学习记录的日期

同一单词当天重复学习只计一次；错题包含在当日学习总数中，同时单独统计。

## 11. 重新开始

完成当前队列后点击“重新开始”，会清空当前词书的累计已学标记并重新生成队列。错题本和历史每日统计不会被删除。

## 12. 数据保存、备份与卸载

用户和学习数据保存在：

```text
%LOCALAPPDATA%\Shiju\users.json
```

- 覆盖安装或升级拾句不会删除该文件。
- 卸载程序默认不会删除学习数据。
- 推荐点击顶部“数据同步”→“导出 JSON 备份”；v2 文件包含四本词书进度、错题、删除状态和温习记录，不包含密码。
- 在另一台电脑或 Android 端点击“数据同步”并选择该 JSON。导入会双向合并新增、删除和温习记录，不会整体清空设备已有数据。
- 旧版 v1 备份仍可导入，但不能表达过去的删除操作。建议先把两端都升级到 1.9.0，再分别导出 v2 并交叉导入一次。
- 如需完整迁移本地账户与登录信息，仍可在关闭拾句后复制整个 `%LOCALAPPDATA%\Shiju` 文件夹；JSON 同步不会迁移账户密码。

## 13. 常见问题

### 点击朗读没有声音

Windows 版会优先调用系统自带的 System.Speech/SAPI 英语语音，并在本机临时生成 WAV；播放结束后不会保留音频，也不会上传文本。如果系统 SAPI 调用失败，程序会自动尝试浏览器语音。请检查 Windows 媒体音量，并在“设置 → 时间和语言 → 语音”中确认已经安装英语语音包。

### 页面没有自动打开

在控制窗口点击“打开学习页面”。控制窗口同时会显示当前实际地址；通常为：

```text
http://127.0.0.1:8765
```

### 端口 8765 被占用或出现 WinError 10013

1.5.1 及以上版本会自动改用一个可用的本机端口，无需手动修改。关闭其他拾句窗口后重新启动即可；控制窗口会显示实际地址。

### Windows 显示“未知发布者”

当前安装包没有商业代码签名证书。确认安装包来源可信后，可选择“更多信息”→“仍要运行”。

### 浏览器关闭后程序仍在运行

这是正常行为。请关闭拾句本地服务控制窗口来停止程序。

### 忘记密码

当前本地版本没有密码找回功能。不要随意修改 `users.json`，以免损坏其他用户数据。
