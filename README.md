## 电脑版：第一次安装

1. 在 Windows 电脑点击顶部“Windows 电脑版”，下载 `Shiju-Windows-Setup.exe`。
2. 双击文件，跟随安装向导点击 Next、Install，完成后打开桌面上的 Shiju（拾句）。
3. 程序会启动本地服务并打开浏览器学习页面。这是正常现象；不要关闭后台控制窗口，否则服务会停止。
4. 默认安装在当前用户目录，普通使用不需要安装 Python。

如果系统显示未知发布者，请先确认文件来自本仓库 Releases。此处的开发者署名不是 Windows 代码签名证书；本发布目录没有重新签署安装包。

## 安卓版：第一次安装

1. 在 Android 手机点击顶部“Android 安卓版”，下载 `Shiju-Android.apk`。
2. 在浏览器下载列表或文件管理器中点开 APK。
3. 若提示不允许安装，按系统提示允许本次使用的浏览器或文件管理器“安装未知应用”，再继续安装。
4. 打开“拾句”，即可使用。适用于 Android 7.0 及以上的 ARM64 手机；不适用于 iPhone 或仅支持 32 位应用的老设备。

**更新前先导出备份。** Android 覆盖升级要求包名、签名一致且版本符合系统要求。若提示签名冲突，不要立即卸载：卸载通常会删除本机学习数据。先导出备份，再反馈问题。

## 第一次学习

1. 按界面提示注册一个本地账户。它用于区分当前设备的学习者，不是联网注册，也不需要 GitHub 账号。
2. 选择词书，设置每日目标。新用户默认使用高中词书和完整例句。
3. 看英文语境中的高亮词，在答案框输入你认为的中文含义，提交后查看解释。
4. 按实际情况选择“回忆成功”或“回忆失败”（部分页面显示“我记住了”或“加入错题本”）。
5. 在“错题本”中复习。在“查词”中输入英文或中文，主动查询不会改变学习记录。

电脑上可用 F2 朗读、F3 查词；手机在页面上点击朗读按钮。语音使用系统 TTS，无法朗读时检查系统是否安装英语语音包。手机专注页面可点击“退出专注”回到完整界面。

错题温习仅“回忆成功”计数，同一单词每天最多计一次，完成规定温习后才能移除。普通学习与错题温习入口的规则可能不同，请以页面提示为准。

## 手机与电脑同步进度

1. 在旧设备顶部打开“数据同步”，导出 JSON 备份，保存到你能找到的位置。
2. 将该 JSON 文件传到另一台设备。
3. 在另一台设备打开“数据同步”，导入备份并按提示完成合并。
4. 两端都继续学习后，可以重复导出并交叉导入。不会自动联网同步。

1.9 系列使用 JSON v2，同步可传播已学／错题的删除记录，并合并温习事件。备份不包含账户密码。不同词书版本可能触发校验提示；同步前建议两端更新到兼容版本，并各自保留一份备份。

## 常见问题

**打开的是网页，是不是装错了？** Windows 版采用本地服务与浏览器界面，这是正常设计。Android 版使用应用内网页界面。

**没有声音？** 检查媒体音量和系统英语 TTS 语音包。应用不保证每台设备的系统语音质量一致。

**进度没有在另一台设备出现？** 数据保存在本机，需要通过“数据同步”导出／导入，不会自动云同步。

**安卓“应用未安装”？** 检查剩余空间、系统版本、CPU 架构，以及是否已有签名不同的旧版。先备份，不要盲目卸载。

**如何备份？** 优先使用程序的数据同步导出。Windows 用户数据位于 `%LOCALAPPDATA%\Shiju`；Android 数据位于应用私有目录，卸载通常会删除。
