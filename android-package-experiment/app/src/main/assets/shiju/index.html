QUICK START · 使用手册

先猜，再看答案

拾句希望你借助词组和例句主动回忆、推测词义，而不是一开始就看翻译。猜错并不可怕，真正费力的回忆更容易留下记忆。

01 · 最快学习方式
  1. 先读词组或例句，根据上下文猜高亮单词的含义。
  2. 有印象就输入自己的答案；实在不记得，直接输入 2，程序会展开解析并加入错题本。
  3. 答案展开后，核对词书释义、词典补充和整句翻译，再决定是否保留为错题。

03 · 句中查词

目标词可能很简单，但例句里也许藏着你没见过的词。提交答案后，点击句中单词即可查阅。

带下划线的单词属于当前词书，可查看词书释义、词典补充和例句；没有下划线的词需确认后查询，只显示词典含义。

也可以点击顶部“查词”，输入英文或中文反查。比如输入“偷”可找到 steal，输入“小偷”可找到 thief；程序会提示 steel / steal 等易混词。

04 · 为什么词书外单词不能加入错题本

词书外词汇数量太多，且相较于当前学习目标优先级较低。为避免错题本失去重点，它们只供临时查询，不支持加入错题本。

05 · 离线朗读

点击“朗读单词”可用较慢速度听目标词发音，点击“朗读词组/例句”可听完整语境。程序优先选择手机中质量最高的离线英语 voice，不上传学习内容；若系统尚未安装高质量英语语音包，需要先在系统语音设置中安装一次。

06 · 复习与进度

错词会继续参与学习循环；每次复习都会累计温习次数，完成第 3 次后才能从“错题本”移除。“历史错题”永久记录曾经出错的词，适合第二轮随机复习。

加入或继续保留错题时会记录本次输入；之后练习该错词时，会显示最近一次被标错时的输入，帮助你辨认此前的误解。

手机端只有亲自点击输入框才会进入专注学习视图；之后例句和今日目标进度固定在上方，下一题会自动打开键盘。换词书、切换词组/例句或打开手册不会触发专注模式；需要返回设置时，点击顶部“退出专注”。

07 · 本地账户说明

本程序未连接云端。账户只用于在同一设备上区分不同学习者，建议使用容易记住的简单用户名和密码，不要使用重要网站的真实密码。卸载程序会清除本机数据；覆盖更新则会保留数据。

之后可随时点击顶部“使用手册”再次查看。
